

# AI Content Marketing Using UGC Ads

## Future Interns – Prompt Engineering Internship
### Task 2

## 1. Project Overview

This project demonstrates how AI-powered prompt
engineering can be used to create authentic and
engaging User-Generated Content (UGC) style
advertisements for a real-world jewellery business.

The selected business is Vimala Jewellery Works,
located in Shivamogga, Karnataka.

## 2. Selected Business

**Business Name:** Vimala Jewellery Works

**Location:** HUDCO Colony, Kariyanna Building,
Shivamogga, Karnataka.

**Products:** Gold and Silver Jewellery.

**Service:** Custom jewellery designing according
to customer designs and orders.

## 3. Project Objectives

- Generate multiple advertisement hooks.
- Create engaging UGC-style ad scripts.
- Use proven advertising frameworks.
- Adapt content for different social media platforms.
- Create reusable prompts for other businesses.

## 4. Tools Used

- ChatGPT – Prompt creation and content generation.
- Google Gemini – AI content comparison and improvement.
- GitHub – Project documentation and storage.
- Canva – Advertisement mockup creation.
- CapCut – Optional video editing.

## 5. Project Features

### Multiple Hooks
Generates different opening lines to capture
the audience's attention.

### UGC-Style Scripts
Creates natural and conversational advertisement
scripts instead of overly promotional content.

### Platform-Specific Content
Generates content for:
- Instagram Reels
- Instagram Ads
- YouTube Shorts

### Clear Calls to Action
Encourages potential customers to visit
the shop or enquire about custom designs.

### Reusable Prompt Structure
The prompts can be adapted for other businesses
by changing their business information.

## 8. Advertising Framework

The project uses the following framework:

**Problem → Solution → Call to Action**

This structure helps identify a customer need,
present a relevant business service and encourage
the audience to take action.

## 9. Conclusion

This project demonstrates the practical use
of prompt engineering in AI-powered content marketing.

It helps businesses generate creative,
platform-specific advertisement content
while reducing manual content creation effort.
