# Prompt Engineering Analysis

## Project
AI Content Marketing Using UGC Ads

## Selected Business
Vimala Jewellery Works, Shivamogga.

## 1. Project Objective

The objective is to use AI-powered prompts to
generate UGC-style advertisements for a jewellery
business.

The advertisements focus on custom gold and
silver jewellery designing.

## 2. Prompt Engineering Techniques Used

### A. Role-Based Prompting
The AI is assigned the role of a professional
UGC advertisement scriptwriter.

This helps the AI generate content related
to social media marketing.

### B. Context-Based Prompting
Business details such as name, location,
products and services are provided.

This helps generate business-specific content.

### C. Instruction-Based Prompting
Clear instructions are given about tone,
length, advertisement structure and output.

This makes the generated content more organised.

### D. Framework-Based Prompting
The Problem → Solution → CTA framework
is used to create advertisements.

It helps present a customer problem,
introduce a solution and encourage action.

### E. Platform-Specific Prompting
Different instructions are provided for
Instagram Reels, Instagram Ads and YouTube Shorts.

This helps adapt the content to different platforms.

## 3. Important Features

- Natural and conversational UGC tone.
- Multiple advertisement hooks.
- Different advertisement scripts.
- Platform-specific content.
- Clear calls to action.
- Reusable prompts for other businesses.

## 4. Benefits of Using AI

1. Saves time in advertisement writing.
2. Generates multiple creative ideas.
3. Helps create different versions of content.
4. Makes content creation easier.
5. Allows prompts to be reused for other businesses.

## 5. Limitations

1. AI-generated content may sometimes contain
   incorrect business information.
2. Generated scripts may need human editing.
3. AI cannot guarantee advertisement performance.
4. Actual business details must be verified.

## 6. Human Review

All generated content should be checked
before publishing.

Business information, product details,
prices and offers must be verified.

## 7. Conclusion

This project demonstrates how prompt engineering
can be used to create UGC-style marketing content.

By combining role-based, context-based,
instruction-based and platform-specific prompting,
AI can generate reusable advertisement content
for different businesses.
